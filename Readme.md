## 👨‍💻 About Me

I'm a **Software Engineering Cadet at 42 Warsaw**, transitioning into
software and game development after more than **4 years in professional
VFX and animation production**.

Before programming full-time, I worked across animation, layout, previs and
compositing pipelines on productions associated with **Disney Junior,
Netflix, Playmobil, Technicolor and 88 Pictures**.

That production background taught me how large technical and creative
pipelines work, how teams solve problems under deadlines, and how tools
affect artists downstream.

At **42 Warsaw**, I'm now developing those same problem-solving skills
closer to the machine through **C, algorithms, data structures, memory
management, Unix/Linux and systems programming**.

My long-term direction is:

**C → C++ → Systems Programming → Game / Engine Development**

I'm particularly interested in the intersection of **software engineering,
real-time graphics, game technology and VFX pipelines**.

# 🚀 Featured Projects

## 🔹 Push_swap

A sorting and algorithmic optimisation project developed as part of the
**42 Warsaw Core Curriculum**.

The program sorts integer stacks using a restricted set of stack operations
while attempting to minimize the number of instructions generated.

### What I'm exploring

`C` · `Algorithms` · `Linked Lists` · `Stack Operations`  
`Sorting Strategies` · `Memory Management` · `Benchmarking`

[View repository →](https://github.com/JassCoder/42_pushSwap)
